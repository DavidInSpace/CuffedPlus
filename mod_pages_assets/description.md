# Cuffed+

An addon for the mod [Cuffed](https://www.curseforge.com/minecraft/mc-mods/cuffed) which adds a lot of new restraints
and prison related items!

### Prison Jumpsuits & Ankle Monitor

* 4 different looking prison jumpsuits.
* Ankle monitor to track where a player is.
* 2 Modifiers

> * Lock Modifier: Makes jumpsuits/ankle monitors lockable using a jumpsuit/ankle monitor key so it can not be taken
    off.
> * High Visibility Modifier: Players wearing a jumpsuit/ankle monitor with this modifier will glow.

### Time Lock

* Lets you restraints for a certain time. After the time runs out the restraint will be automatically unlocked!

### Police Uniform

* Adds 1 police uniform for players to wear.

### Restraints

* Wooden cuffs, golden cuffs, diamond and netherite cuffs each material has a different durability.
* Hazard tape: just like normal tape but with a different texture.
* 4 Restraint Modifiers.

> * Saturation Modifier: Player wont loose hunger.
> * Hunger Modifier: Player will loose hunger faster.
> * Anti-God Modifier: If the player is in creative he will be put in to survival.
> * Lockpickable: Restraints with this modifier can't be lock picked.

### Config Options

* This addon adds to a lot of options so you can configure everything to your needs. You can find more info about that
  on the [wiki]((https://github.com/DavidInSpace/CuffedPlus/wiki))

For more info about all items, restraints, mechanics and config options take a look at
